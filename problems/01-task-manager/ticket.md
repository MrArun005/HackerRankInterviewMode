# React: Task Manager

Complete a React task manager application in order to pass all the unit tests.

- The task list displays every task with a checkbox and its text.
- The user can type into the input and press **Add** to append a new task.
- Three filter buttons — All, Active, Completed — control which tasks are shown.
- A counter below the list shows how many tasks are not yet complete, in the form **"N remaining"**.

**Required data-testids:** `taskInput`, `addTaskBtn`, `taskList`, `taskCount`, `filterAll`, `filterActive`, `filterCompleted`, and per row `taskCheckbox-{index}`.

**Read only:** the TESTS block.

> The ticket says "N remaining". The tests have different wording, and an
> opinion about the singular. Read them.
